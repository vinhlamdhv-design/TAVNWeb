Biểu tượng HTML Noise_Heatmap_App HTML Đang mở Hướng dẫn sử dụng: Tải tệp HTML về máy: Nhấn vào nút tải xuống để tải file Noise_Heatmap_App.html về máy tính của bạn và mở nó bằng bất kỳ trình duyệt web nào (Chrome, Edge, Safari,...). Chèn Bản đồ (Mặt bằng): Tại mục (1), bạn hãy tải lên file hình ảnh mặt bằng khu vực của bạn (định dạng JPG hoặc PNG). Lấy hệ tọa độ (Mapping): Sau khi chèn ảnh lên, bạn có thể click chuột vào các vị trí cụ thể trên hình ảnh mặt bằng. Trình duyệt sẽ hiển thị tọa độ (x, y) góc trên cùng bên phải. Bạn hãy lưu lại các tọa độ này vào một file Excel. Tạo dữ liệu tiếng ồn: Mở Excel/Google Sheets, tạo một file bao gồm 3 cột có tiêu đề (Header) bắt buộc là: x, y, và noise. Điền tọa độ bạn vừa thu thập và mức độ tiếng ồn tương ứng tại vị trí đó (ví dụ cột noise: 60, 80, 110...). Lưu (Save as) file Excel này dưới định dạng .CSV. Hiển thị Sơ đồ nhiệt (Heatmap): Tại mục (2), tải file CSV bạn vừa tạo lên. Sơ đồ nhiệt mức độ ồn sẽ tự động được vẽ đè lên hình ảnh mặt bằng đã chèn trước đó (màu xanh/vàng cho tiếng ồn thấp, màu đỏ cho tiếng ồn cao). Công cụ này chạy hoàn toàn trên trình duyệt offline của bạn, không cần cài đặt thêm phần mềm và bảo mật tuyệt đối với dữ liệu nội bộ. Dưới đây là các bước chi tiết để đưa ứng dụng của bạn lên GitHub: Bước 1: Tạo tài khoản và đăng nhập GitHub Truy cập vào trang web github.com. Nếu chưa có tài khoản, nhấn vào Sign up để đăng ký. Nếu đã có, nhấn Sign in để đăng nhập. Bước 2: Tạo một Repository (Kho lưu trữ) mới Tại góc trên cùng bên phải màn hình, nhấn vào dấu + và chọn New repository. Tại mục Repository name, nhập một tên bất kỳ viết liền không dấu (ví dụ: noise-heatmap-app). Đảm bảo chọn quyền riêng tư là Public (Bắt buộc để sử dụng GitHub Pages miễn phí). Kéo xuống dưới cùng và nhấn nút xanh Create repository. Bước 3: Tải file ứng dụng lên GitHub Trong màn hình repository vừa tạo, tìm mục Quick setup và nhấp vào đường dẫn uploading an existing file (Tải lên một file có sẵn). Kéo thả file Noise_Heatmap_App.html (đã tải về ở bước trước) vào khung tải lên. Lưu ý quan trọng: Để đường link ứng dụng ngắn gọn và tự động chạy, bạn nên đổi tên file Noise_Heatmap_App.html thành index.html trước khi tải lên. Kéo xuống phần Commit changes, nhập một đoạn mô tả ngắn (ví dụ: Tải lên file sơ đồ nhiệt) và nhấn nút xanh Commit changes. Bước 4: Kích hoạt GitHub Pages Tại repository của bạn, nhìn lên thanh menu nằm ngang phía trên mã nguồn, chọn tab Settings (biểu tượng bánh răng). Ở thanh menu bên trái, kéo xuống mục Code and automation và chọn Pages. Tại phần Build and deployment, ở mục Source, đảm bảo đang chọn Deploy from a branch. Ngay bên dưới mục Branch, nhấp vào nút None, chọn main (hoặc master), sau đó nhấn nút Save. Bước 5: Lấy đường link ứng dụng Sau khi nhấn Save, hãy đợi khoảng 1 đến 3 phút để GitHub xử lý. Tải lại (Refresh) trang web. Bạn sẽ thấy một thông báo ở đầu phần GitHub Pages hiển thị nội dung: "Your site is live at https://[tên-tài-khoản-của-bạn].github.io/[tên-repository]/".
